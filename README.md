# jianpu-editor

丝滑的网页简谱（numbered musical notation）编辑器。

在线体验：https://jianpu.webkubor.online/

## 技术栈

**不使用任何前端框架，也没有组件库。**

- **构建工具**：Vite 6（仅构建期；产物无任何框架运行时）
- **语言**：TypeScript 5（strict 模式，构建时 `tsc --noEmit` 全量类型检查）
- **UI 层**：原生 DOM。`index.html` 手写完整界面骨架（约 540 行静态 DOM），`src/app/main.ts` 用 `getElementById` 直接绑定；**没有 React / Vue / Svelte，没有虚拟 DOM，没有组件树**
- **渲染层**：自研 SVG 排版引擎（`src/render/`）——数字 + 圆点 + 横线直接画成 SVG 元素，不用音符字体，canvas `measureText` 离屏测宽、段落两端对齐、超宽自动按小节换行
- **音频层**：自研 Web Audio 合成器（`src/core/player.ts`）——正弦 + 泛音物理合成，零音频库
- **运行时依赖**：**0 个**（`dependencies` 为空；`devDependencies` 仅 vite / typescript / @types/node，全部只用于构建和测试）
- **测试**：Node.js 内置 test runner（`node --test`），195 个测试覆盖核心逻辑，零测试框架依赖

为什么不用框架：本项目是**排版引擎 + 物理回放**，核心是纯计算（`src/core/`）与 SVG 生成（`src/render/`），这两层不需要框架；UI 交互（键盘、工具栏、对话框）用原生 DOM 事件已足够，且换来零运行时开销与极小产物体积（gzip 后 ~46KB）。

> **已知取舍（v0.2 计划）**：当前 UI 层（`src/app/`，约 1500 行）是手动状态-DOM 同步——67 处 `getElementById`/`addEventListener`、大量手动 `classList`/`textContent` 更新。状态交叉多的场景（播放高亮、卡拉OK 歌词、撤销栈）维护成本会随功能增长。v0.2 计划将 **UI 层迁移到 Vue 3**（`src/core/` 计算层与 `src/render/` 排版引擎保持不变，它们不依赖 DOM 框架），以获得声明式状态绑定。迁移前先发布当前可用版本。

## 核心思路

1. **一切皆符号**：音符 / 延音线 / 小节线统一为扁平 `Notation` 节点，渲染、播放、DSL 投影共享同一数据源。
2. **节拍分组推断时值**：存储层只存显式属性，空格分组的 n 个音在编译层平分一拍（自动减时线、真实时值 `beatFrac`，三连音 1/3 拍精确播放）。
3. **SVG 纯文本排版**：不用音符字体，数字 + 圆点 + 横线直接画，canvas measureText 测宽、段落两端对齐、超宽自动按小节换行。
4. **Web Audio 回放**：正弦 + 泛音合成，Enter 全谱试听，连音线同音高合并成持续音，播放高亮 + 卡拉OK歌词高亮 + 滚动跟随；输入与调音具备即时单音听觉反馈。

| 键 | 作用 |
|---|---|
| `1`–`7` | 音符（继承前音八度） |
| `空格` | 延音线 |

| `←→` / `↑↓` | 移动光标 / 换段 |
| `Home` / `End` (或 `⌘←` / `⌘→`) | 光标快速跳到当前段首 / 段尾 |
| `⌥↑↓` | 段落重排（整段上下移，可撤销） |
| `+` / `-` | 高低八度 |
| `#` / `b` | 升降变音记号循环切换（无 → ♯ → ♭ → 无） |
| `;` | 演奏记号循环切换（无 → ▾ 顿音 → 𝄐 延长 → ⌒ 保持音 → 无） |
| `.` | 附点 |
| `[` / `]` | 减 / 加减时线 |
| `~` | 连音线开 / 关 |
| `L` | 写歌词（修饰光标左边音符） || `⇧L` | 连续填词模式：打字累积成词（支持输入法中文），空格/回车提交并自动跳到下一音符，Esc 退出 |
| `⇧Enter` / `⌘⇧Enter` | 拆段 / 整段复制到下方（旋律重复高频操作） |
| `⌘D` | 复制当前小节（歌词随行，可撤销） |
| `⌘⌫` | 删除当前整段（最后一段保留只清内容） |
| `Backspace` / `Delete` | 向左退格删除 / 向右删除音符 |
| `⌘↑` / `⌘↓` | 全谱升半音 / 降半音转调 |
| `⌘S` | 快捷保存乐谱工程 (`.jianpu.json`) |
| `?` | 随时打开全键盘快捷键速查面板 |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |
| `Enter` | 播放 / 停止（Shift+Enter 从光标处播；播放中可继续编辑，高亮照常推进） |

工具栏：曲名 / 调号 / 速度 / 拍号 / 作者、**经典曲库预设（送别 / 康定情歌 / 茉莉花）**、**🔊 音量滑块调节**、**⏱ 节拍器伴奏打点**、♭♯ 半音、**📄 新建空白乐谱**、保存 / 打开 `.jianpu.json`、**打开/导入标准 .mid / .midi 文件自动逆向转谱**、**PNG / 📐SVG 矢量 / 🎵MIDI 导出 / 🔊WAV 音频离线导出**、**🖨 打印 / 另存为 A4 PDF**、DSL 灌入 / 导出。MIDI 可直接导入 DAW / 打谱软件（真实时值：附点、三连音、延音线合并）。

## DSL

```
[词:春 风]
6, 1 2 3  5 - 3 | 2 - - ‖
```

- 空格 = 拍内分组（n 音平分一拍，三连音自动生成顶部 `3` 连音括弧）；**双空格 = 拍边界**
- `|` / `‖` 小节线与终止线；`||:` / `:||` 反复开始与结束小节线（附带左右双圆点）
- `-` 延音；`~` 连音线；`,` 低八度、`'` / `^` 高八度；`#` / `b` 变音；`.` 附点；`{▾}` / `{𝄐}` 演奏记号后缀
- `[词:…]` 歌词行修饰**上方**音符行，空格分词、`-` 占位
- **中文输入法友好**：全角 `１２３`、`　`、`，`、`｜`、`～`、`．`、`－`、`＾`、`＃`、`ｂ` 自动归一化
- **画布直接 ⌘C / ⌘V / 拖拽导入**：⌘C 复制全谱 DSL（含时值/连音/歌词），⌘V 粘贴简谱文本直接变谱子；直接把 `.jianpu.json` 或 `.mid` 文件拖拽落到画布即可秒速导入加载。

## 保障

- 小节拍数实时校验（状态栏 ⚠ 提示异常小节）
- `.jianpu.json` 结构校验，损坏文件拒开且不污染自动保存
- 下载文件名安全净化（标题含 `/` `:` 等不炸）
- 自动保存（localStorage），刷新不丢稿
- 撤销 / 重做 100 步；打开新文件 / 灌入 DSL 视为新起点（清栈防串谱）
